RNA-seq preprocessing tutorial: Raw QC + Adapter/Quality Trimming

A module-wise, production-ready tutorial for SurvOm. Users can run Raw Read QC and Adapter/Quality Trimming separately, or run them as one guided workflow on local infrastructure, Docker, HPC, or AWS Batch.

COMMON module — reusable across omics Nextflow DSL2 ready Guided UI + Chat workflow Validated command flags Generated 2026-06-18

Design decision

The best product design is two atomic modules plus one wrapper flow. This keeps each module testable and reusable, while giving beginner users a single guided “preprocess my FASTQs” experience.

Separate user, expert, and internal parameters.

Module 03 — Raw Read Quality Control

This module runs before reads are changed. It gives users confidence in the starting data and gives the platform evidence for whether trimming is recommended.

Inputs

staged_fastq_manifest from step 02
fastq_1 for each sample
fastq_2 for paired-end samples
Optional custom adapter / contaminant files for expert mode

Outputs

*_fastqc.html visual report
*_fastqc.zip machine-readable FastQC archive
raw_qc_summary.json for UI/chat
raw_qc_status.tsv for tables and exports

Tool choice

RoleToolUse whenWhy
DefaultFastQCStandard bulk RNA-seq and most guided workflows.Mature, familiar, stable output, strong MultiQC support.
FallbackFalcoLarge cohorts where QC runtime becomes a bottleneck.FastQC-compatible output with faster execution in many datasets.

FastQC parameters

ParameterCLI flagDefaultExpose?User meaning

custom_adapters--adaptersnullexpertAdapter list file for special protocols.
custom_contaminants--contaminantsnullexpertKnown contaminants file for overrepresented sequence checks.
extract_zip--extracttrueinternalKeep true so downstream parsers can read extracted files.
fail_on_fastqc_warnplatform rulefalseinternalDo not hard-fail on biological QC warnings.
Product rule: Do not fail a workflow only because a FastQC module reports WARN/FAIL. Use those flags to explain data quality and recommend trimming or post-trim review.

Module 04 — Adapter and Quality Trimming

This module removes adapters, poor-quality read tails, and platform-specific artifacts such as polyG tails. It is optional, but in a guided RNA-seq workflow it should usually run unless raw QC is clean and an expert chooses to skip it.

Inputs

staged_fastq_manifest or raw FASTQ paths
raw_qc_summary.json to guide trimming recommendation
Optional explicit adapter sequences
Optional platform metadata for polyG trimming

Outputs

*.trimmed.fastq.gz cleaned reads
trimmed_fastq_manifest for downstream steps
*.fastp.html visual trimming report
*.fastp.json machine-readable metrics

Tool choice

RoleToolUse whenWhy
DefaultfastpStandard guided preprocessing.Adapter detection, quality filtering, polyG/polyX trimming, JSON and HTML reports in one tool.
FallbackCutadaptExact custom adapters or reproduction of older studies.Precise adapter grammar: 3′, 5′, linked, anchored, paired adapter handling.

Nextflow implementation pattern

Keep module code separate from workflow orchestration. The wrapper workflow chooses which modules to run based on workflow_mode.

main.nf skeleton

main.nf
nextflow.enable.dsl=2

include { FASTQC } from './modules/common/fastqc/main'
include { FALCO  } from './modules/common/falco/main'
include { FASTP  } from './modules/common/fastp/main'
include { CUTADAPT } from './modules/common/cutadapt/main'
include { MAKE_PREPROCESS_MANIFEST } from './modules/common/make_manifest/main'

workflow {
    Channel
        .fromPath(params.input)
        .splitCsv(header: true)
        .map { row ->
            def meta = [ id: row.sample_id, single_end: row.library_layout == 'single', platform: row.platform ?: 'unknown' ]
            def reads = meta.single_end ? [file(row.fastq_1)] : [file(row.fastq_1), file(row.fastq_2)]
            tuple(meta, reads)
        }
        .set { reads_ch }

    if (params.workflow_mode in ['raw_qc_only','raw_qc_plus_trimming','full_preprocess_qc']) {
        if (params.qc_tool == 'falco') FALCO(reads_ch)
        else FASTQC(reads_ch)
    }

    if (params.workflow_mode in ['trimming_only','raw_qc_plus_trimming','full_preprocess_qc']) {
        if (params.trimming_tool == 'cutadapt') CUTADAPT(reads_ch)
        else FASTP(reads_ch)
    }

    MAKE_PREPROCESS_MANIFEST()
}

AWS Batch profile

On AWS Batch, every process must run in a container and the Nextflow work directory should be in S3. Keep the same workflow parameters; only change the execution profile and paths.

conf/aws.config
profiles {
  aws {
    process.executor = 'awsbatch'
    process.queue = 'survom-rnaseq-queue'
    aws.region = 'eu-north-1'
    workDir = 's3://survom-rnaseq/work/'

    docker.enabled = true

    process.withName:FASTQC {
      container = 'biocontainers/fastqc:v0.12.1_cv4'
      cpus = 4
      memory = '8 GB'
    }

    process.withName:FALCO {
      container = 'quay.io/biocontainers/falco:1.3.2--h077b44d_0'
      cpus = 4
      memory = '4 GB'
    }

    process.withName:FASTP {
      container = 'quay.io/biocontainers/fastp:0.23.4--h5f740d0_0'
      cpus = 4
      memory = '8 GB'
    }

    process.withName:CUTADAPT {
      container = 'quay.io/biocontainers/cutadapt:5.1--py313h1a76870_0'
      cpus = 4
      memory = '8 GB'
    }
  }
}
Operational tip: For production AWS, keep FASTQ input and output S3 buckets in the same region as the Batch compute environment to reduce latency and data transfer surprises.

QC rules and user messages

Raw QC rules

Warn if adapter content is high.
Warn if per-base quality degrades strongly at read ends.
Warn if GC distribution is abnormal.
Warn if duplication is unusually high.
Fail only if input cannot be read or report is not produced.

Trimming rules

Warn if <80% reads retained.
Warn if adapter content remains high after trimming.
Fail if trimmed FASTQ is empty.
Fail if <50% reads retained unless expert override is approved.

User-facing messages

ConditionUI messageSuggested action
Adapter content high before trimming“Adapter contamination detected in raw reads.”Run trimming with fastp default settings.
Low quality at read ends“Read quality drops near the end of reads.”Use Q20 quality trimming; inspect post-trim QC.
Many reads discarded“Trimming removed more reads than expected.”Check adapter sequence and minimum length threshold.
Clean raw QC“Raw reads look clean.”Allow expert skip, but guided mode can still run light trimming.
